# 学习者档案

> 导师每次开课前会读这个文件来「认识你」。请按实际情况修改下面的内容，越准确，引导越贴合你。

## 基本设定

- **学习目标**：吃透 AskLens 源码与架构，能在面试中清晰讲解每个技术决策。
- **核心动机**：面试准备（把项目讲成简历亮点）+ 真正理解企业级 RAG 系统。
- **当前阶段**：V1（认证与群组）已完成，V2（文档引擎）已完成，从V3开始
- **每次学习时长**：约 1–2 小时（请按实际调整）。

## 背景（帮我把握讲解深度）

- **已掌握**：基础 RAG（切片 → Embedding → 向量检索 → LLM 生成）、Spring AI 入门（ChatClient、Embedding、简单 RAG）、Java + Spring Boot 基本功。
- **较薄弱 / 想重点补**：并发与异步、设计模式落地，RAG文档切分，系统边界与安全问题
- **完全没接触过**：pgvector、ReactAgent 图引擎等

## 学习偏好

- **风格**：纯苏格拉底式——先逼我思考再揭示，别直接喂答案。
- **语言**：中文讲解。
- **遇到代码细节**：必须基于真实源码，不要臆造。
- **节奏**：先跑通主线，细节按需深挖

## 我特别在意的面试问题

> 列几个你最怕被问、或最想答好的问题，导师会重点帮你打磨。

- 「你简单介绍一下你的项目吧」
- 「这个项目是你自己做的，还是公司里面在用的」
- 「你在这个项目中担任什么角色，做了哪些事情」
- 「关于RAG，你了解多少」
- 「关于现在大模型的幻读，你是怎么解决的」
