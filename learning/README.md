# 苏格拉底导师 · 使用说明

一套用 Markdown 搭的**苏格拉底式学习系统**，带你用「问题驱动、自己推理」的方式吃透 AskLens 源码，并为面试做准备。灵感来自 [ostep-socratic-tutor](https://github.com/lmonkt/ostep-socratic-tutor)，但去掉了角色扮演，做成**纯导师**版本。

## 两条学习轨道

| 轨道 | 学什么 | 教学法 |
|------|--------|--------|
| **A · AskLens 源码** | 吃透你真实项目的源码与架构 | 纯苏格拉底 |
| **B · 大模型面试题** | 刷透通用大模型/Agent 八股（200+ 题） | 苏格拉底 + 输出闭环（理解→输出→模拟→复习） |

两条轨道**共用**学习者档案（`learner-profile.md`）和复习队列（`review-log.md`），薄弱点可跨轨道间隔复习。

## 怎么开始（每次都一样）

新开一个对话，第一句话发：

```
请阅读 @learning/system.md，按里面的规则继续我的苏格拉底式学习。
```

导师会先问你今天走哪条轨道；选轨道 B 时会自动改读 `llm-interview/tutor.md`。也可以直接指定：

```
请阅读 @learning/llm-interview/tutor.md，开始大模型面试题轨道的学习。
```

导师会自动读进度、挑今天的内容、开始用问题引导你。就这么简单，不用每次重写一长串提示词。

## 上课时常用的话

- `继续` —— 下一小步
- `提示` —— 给个小线索（不给答案）
- `我卡住了` —— 把问题拆得更小
- `去源码` —— 打开真实代码一起读
- `画图` / `举个例子` / `对比一下` / `动手`
- `总结` —— 核心总结 + 30 秒面试话术
- `面试模拟` —— 我当面试官追问你
- `复习` —— 抽查你的薄弱点
- `下课` —— 保存进度、提醒填笔记

完整命令表见 `system.md` 第四节。

## 文件结构

| 文件 | 作用 | 谁来改 |
|------|------|--------|
| `system.md` | 导师的「大脑」+ 轨道选择入口；轨道 A 的角色、铁律、流程、命令 | 一般不动 |
| `learner-profile.md` | 你是谁、目标、背景、偏好（两轨道共用） | **你先填一下** |
| `progress.md` | 轨道 A（AskLens 源码）进度 | 导师自动维护 |
| `review-log.md` | 薄弱点 + 间隔复习队列（**两轨道共用**） | 导师自动维护 |
| `llm-interview/tutor.md` | 轨道 B（大模型面试题）的大脑：混合四步闭环、命令、课程地图、诚实红线 | 一般不动 |
| `llm-interview/progress.md` | 轨道 B 进度 | 导师自动维护 |
| `llm-interview/docs/` | 面试题原料：路线图、八股文、STAR 稿、问答集等 | 你的素材 |

## 和现有 docs/ 的关系

这套系统**驱动**你已有的学习资料，不重复造轮子：

- 课程大纲 → `docs/AI-学习引导提示词.md`
- 学完填笔记（用自己的话）→ `docs/AI-学习笔记模板.md`
- 阶段自测 → `docs/面试自测清单.md`
- 背景资料 → `docs/AskLens-学习指南.md` + `docs/V*.0-项目文档.md` / `V*.0-设计决策.md`

## 建议的学习闭环

1. **上课**：`@learning/system.md` 开课，跟着问题推理；
2. **验证**：用 `动手` / `去源码` 在代码、Postman、SQL、日志里亲手确认；
3. **沉淀**：当天去 `docs/AI-学习笔记模板.md` 用自己的话写（别复制粘贴）；
4. **复盘**：阶段结束用 `docs/面试自测清单.md` 口头自测，答不上的回头 `复习`。

## 第一步

先打开 `learning/learner-profile.md` 填一下你的背景和薄弱点，然后就可以开课了。
